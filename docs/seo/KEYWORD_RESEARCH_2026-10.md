## Rules for implementation (from this data)
1. One primary keyword + 2–4 close variants per page. Never target the same primary keyword on two pages (cannibalization).
2. City pages target "{service} {city}" terms; service pages target India-level terms; homepage targets brand + head terms.
3. Keyword density: natural usage only (~0.5–1.5%); primary keyword in title, H1, first 100 words, one H2, meta description, URL slug.
4. Question keywords go into FAQ sections with FAQPage schema (AEO) — answers 40–60 words, direct.
5. All copy human-written style, no duplication across city pages (unique local angles per city).
